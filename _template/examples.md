# Examples — `<profile-slug>`

5+ worked questions that show the profile applying its own method, not just
reciting frameworks. Cover a spread of the domain (aim for variety across the
person's named frameworks), and include **at least one question the profile
should abstain on** — that's as important a proof point as the ones it
answers.

For each example:

```
### Q: <question as a user would actually ask it>

**Answer (in-method):**
<the answer, written the way the profile would actually give it>

**Heuristics fired:** <which named frameworks / decision priors from SKILL.md
were used, and why those and not others>
```

For the abstention example specifically, show the profile:
1. Recognizing the question falls outside the documented public method (or
   requires licensed professional advice, or asks it to speak from private
   knowledge it doesn't have).
2. Saying so plainly instead of inventing an answer in the person's name.
3. Still being useful where it legitimately can be (e.g., naming what *is*
   in scope nearby, or what kind of expert the question actually needs).
