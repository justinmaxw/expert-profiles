# Sources — `<profile-slug>`

The evidence file for this profile. Enough detail that a skeptic can audit
the brain: every non-obvious claim in `SKILL.md` should trace back to a row
here.

Rules:
- Primary sources first (their own books, talks, posts, interviews).
  Wikipedia and commentator roundups are for finding primaries, not for
  citing claims — list them separately under "Secondary" if used at all,
  and say what they were used for.
- Date every row. If a source is undated, say so and explain how you bounded
  it (e.g., "referenced a 2024 book, so after that date").
- Never cite a quote you did not see the text of. If a claim came through a
  transcript, summary, or aggregator site rather than the original video/
  audio/book, say so in the "Accessed via" column — that is a real
  limitation on verifiability and should be visible, not hidden.
- If two sources disagree, keep both rows and note the disagreement in
  "What it contributed."
- Omit any claim you could not source. Do not backfill with a vague citation.
